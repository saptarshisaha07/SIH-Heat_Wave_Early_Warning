# Bhubaneswar Heat Wave Early Warning System
### SIH26083 — AI-Powered Hyper-Local Heat Wave Risk & Vulnerability Assessment

An intelligent, ward-level heatwave monitoring, risk assessment, and early warning platform for the Bhubaneswar Municipal Corporation. Integrates live atmospheric observations, thermal comfort indices (Heat Index, WBGT), demographic vulnerability modeling, 3-day machine learning predictive forecasts, and persona-specific public health advisories into a single-port dark-themed dashboard.

---

## Problem Statement

Rapid urbanization and climate change have intensified urban heat island (UHI) effects, leading to severe thermal stress and heat-related illnesses in rapidly developing Indian cities like Bhubaneswar. Conventional weather forecasts provide broad regional summaries that fail to capture:
1. **Hyper-Local Variation**: Microclimatic differences across distinct municipal zones and urban density corridors.
2. **Socio-Demographic Vulnerability**: The amplified risk faced by vulnerable populations (elderly citizens, children, and outdoor informal workers) residing in high-density wards.
3. **Actionable Preparedness**: Proactive, multi-horizon risk projections and role-specific advisories needed by municipal disaster authorities before extreme heat events occur.

**SIH26083** calls for an end-to-end early warning system that bridges the gap between raw meteorological data, demographic exposure, predictive machine learning, and actionable municipal public health response.

---

## What This Demo Does

When you open the interactive dashboard, you can:
1. **Explore the Municipal Risk Map**: View all 10 Bhubaneswar municipal zones on a dark-themed geospatial map with real-time glowing circle markers color-coded across 5 risk severity levels (Normal, Caution, Extreme Caution, Danger, Extreme Danger).
2. **Inspect Real-Time Atmospheric & Thermal Stress**: Click on any ward marker to inspect live temperature, relative humidity, wind speed, solar radiation, NOAA Heat Index, and simplified Wet Bulb Globe Temperature (WBGT).
3. **Analyze Demographic Vulnerability**: View the ward's population demographics (elderly % and outdoor worker %) and inspect how demographic exposure amplifies the base heat hazard.
4. **Read the Composite Risk Score Gauge**: View an interactive horizontal gradient gauge bar (0–100) indicating exact composite risk with a positioned needle indicator and colored category pill.
5. **Toggle Evaluation Modes**: Switch between **Vulnerability-Adjusted** (amplified risk) and **Heat-Only** (pure meteorological hazard) modes with instant in-place marker recoloring and UI updates from client cache.
6. **Track 3–5 Day Predictive ML Forecasts**: View projected Heat Index trajectories for $t+1, t+2, t+3$ generated by a trained multi-output Random Forest regressor, plotted over colored risk-severity background bands.
7. **Review Role-Specific Public Health Advisories**: Read tailored precautions categorized for outdoor workers and vulnerable demographics.
8. **Inspect Score Explainability**: View a comparative bar chart breaking down the Base Heat Score, Vulnerability Adjustment, and Final Composite Score.
9. **Simulate Emergency Alerts**: Trigger a simulated emergency broadcast to generate realistic, persona-targeted SMS and WhatsApp alert notifications logged to the database.

## Scope Note

* **Mortality Modeling**: Real clinical mortality and morbidity prediction requires restricted hospital admission records, health registries, and long-term epidemiological time-series data not accessible for an open hackathon prototype. In place of a black-box mortality model, this system implements an authoritative, explainable composite risk model combining established biometeorological equations (NOAA Heat Index & Australian BOM WBGT) with a normalized vulnerability amplification function (+30% maximum scaling cap).
* **Machine Learning Horizon**: The ML forecasting engine uses a multi-output `RandomForestRegressor` trained on 3-day daily-aggregated atmospheric lag features ($t, t-1, t-2$) to predict short-term actionable heat stress ($t+1, t+2, t+3$), rather than multi-week seasonal climate outlooks.
* **Demographic Data**: Spatial boundaries and demographic indicators (population, elderly percentage, outdoor worker percentage) for Bhubaneswar municipal zones are synthesized from public census demographics for demonstration purposes.
* **Alert Dispatch**: The alert system simulates multi-channel SMS and WhatsApp delivery with realistic formatting, audit logging, and explicit simulation disclosures; no paid SMS gateway (e.g. Twilio) is connected.

## Tech Stack

| Layer | Technology | Why Used |
| :--- | :--- | :--- |
| **Backend Framework** | **FastAPI** (Python 3.10+) | High-performance asynchronous REST API framework with native OpenAPI/Swagger docs and integrated static file serving. |
| **Server & Runtime** | **Uvicorn** (ASGI) | Production-ready ASGI web server enabling unified single-port (`8000`) serving of both APIs and frontend assets. |
| **Database & ORM** | **SQLite + SQLAlchemy 2.0** | Lightweight, zero-configuration relational database with declarative ORM models and idempotent seeding. |
| **Machine Learning** | **Scikit-Learn (`RandomForestRegressor`) + Joblib** | Multi-output ensemble regression model predicting multi-day Heat Index lag projections with instant local inference. |
| **Data Processing** | **Pandas & NumPy** | High-performance tabular manipulation for time-series feature engineering, daily aggregation, and lag extraction. |
| **Background Scheduler** | **APScheduler (v3.10+)** | Background cron service automatically ingesting live weather observations and updating risk scores every 45 minutes. |
| **Geospatial Mapping** | **Leaflet.js (v1.9.4) + CARTO Dark Matter / OSM** | Lightweight interactive mapping with custom SVG glowing circle markers and dark cartography. |
| **Data Visualizations** | **Chart.js (v4.4.1)** | Canvas-based charting for multi-day forecast trajectories and risk score explainability breakdowns with custom canvas plugins. |
| **Frontend UI** | **Vanilla HTML5, CSS Grid / Flexbox, Modern JS (ES6+)** | Dependency-free, responsive dark glass-card interface with zero framework overhead and instant client-side caching. |
| **Weather Ingestion** | **Open-Meteo Forecast & Archive APIs** | Free, open-access meteorological API for live and historical atmospheric observations without API key restrictions. |

### Backend
* Encapsulates all data ingestion, mathematical thermal indices, demographic vulnerability calculations, machine learning inference, and database persistence.
* Implements robust offline resilience (Task 24): on external API rate-limiting or network failure, it automatically falls back to cached readings with HTTP 200 rather than crashing.

### ML
* **Model**: Multi-output `RandomForestRegressor` predicting $t+1, t+2, t+3$ daily Heat Index values simultaneously.
* **Features**: 18-dimensional feature vector including 3-day temperature lags (`lag0`, `lag1`, `lag2`), humidity lags (`lag0`, `lag1`), wind speed, seasonal calendar indicators (`month`, `day_of_year`), and one-hot encoded ward indicators.

### Frontend
* Single-page, framework-free dashboard served directly by FastAPI.
* Employs CSS Grid for responsive 2-column card reflow, Leaflet with SVG filter drop-shadows for glowing risk markers, and Chart.js canvas plugins for colored meteorological threshold bands.

## Getting Started

### Backend Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/saptarshisaha07/SIH-Heat_Wave_Early_Warning.git
   cd SIH-Heat_Wave_Early_Warning
   ```

2. **Create and activate a Python virtual environment**:
   * **Windows (PowerShell)**:
     ```powershell
     python -m venv backend/.venv
     .\backend\.venv\Scripts\Activate.ps1
     ```
   * **macOS / Linux**:
     ```bash
     python3 -m venv backend/.venv
     source backend/.venv/bin/activate
     ```

3. **Install Dependencies**:
   ```bash
   pip install -r backend/requirements.txt
   ```

4. **Initialize Database & Seed 5-Day Historical Weather**:
   ```bash
   python backend/app/seed.py
   python backend/scripts/backfill_weather_history.py --days 5
   ```

5. **Run Automated Tests (Verify 61 Tests Pass)**:
   ```bash
   cd backend
   python -m unittest discover -s tests -p "test_*.py"
   cd ..
   ```

6. **Launch the Unified Server**:
   ```bash
   uvicorn app.main:app --app-dir backend --reload --port 8000
   ```

### Frontend Setup

No separate build steps or Node.js toolchains are required. The entire frontend is served directly by the FastAPI backend on port `8000`.

* **Open the Web Dashboard**: Open [http://127.0.0.1:8000/](http://127.0.0.1:8000/) in your web browser.
* **Interactive Swagger Docs**: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
* **ReDoc Documentation**: [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)

## API Endpoints

| Method | Path | Description |
| :--- | :--- | :--- |
| `GET` | `/` | Serves the interactive web map dashboard (`index.html`) |
| `GET` | `/health` | Service health status check (`{"status": "ok"}`) |
| `GET` | `/api/risk-map` | GeoJSON `FeatureCollection` of all 10 wards with coordinates, vulnerability indices, and dual risk scores |

| `GET` | `/api/advisories/{category}` | Specific public health advisory for a risk category and target audience |

| `GET` | `/redoc` | Alternative ReDoc interactive documentation UI |

The spatial coordinates, population figures, elderly percentages, and outdoor worker distributions for the 10 Bhubaneswar municipal zones are synthesized from public census demographics for demonstration and prototyping purposes.
